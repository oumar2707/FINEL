# FINEL - Forum de l'Innovation Numérique à Labé

Bienvenue dans le dépôt officiel du site web du **FINEL 2026**.

## 🌟 À propos du projet

Le **FINEL** (Forum de l'Innovation Numérique et de l'Entrepreneuriat Étudiant) est l'événement phare de l'Université de Labé. Ce site web a été conçu pour présenter l'événement, son programme, ses intervenants et permettre aux étudiants et professionnels de s'inscrire en ligne.

L'objectif est de dynamiser l'écosystème numérique de la région de Labé en offrant une plateforme d'échange, d'inspiration et de networking.

## 🚀 Fonctionnalités

- **Design Premium & Moderne** : Une interface utilisateur élégante avec des effets de glassmorphism et des animations fluides.
- **Hero Slider Dynamique** : Une présentation visuelle impactante des objectifs du forum.
- **Programme de l'Événement** : Accès détaillé aux conférences, ateliers et sessions de networking.
- **Système d'Inscription** : Formulaire optimisé pour la réservation de places.
- **Galerie Interactive** : Retour en images sur les éditions précédentes.
- **Cartographie** : Localisation précise de l'événement à l'Université de Labé via Google Maps.
- **Responsive Design** : Entièrement compatible avec les mobiles, tablettes et ordinateurs.

## 🛠️ Technologies utilisées

- **HTML5** : Structure sémantique et optimisée SEO.
- **CSS3 (Vanilla)** : Design personnalisé, Flexbox, Grid et animations complexes.
- **JavaScript** : Pour les interactions et le dynamisme du site.
- **Google Fonts** : Utilisation de la police 'Inter' pour une lisibilité maximale.
- **Font Awesome** : Bibliothèque d'icônes pour une interface intuitive.
